# BDT Talent Group Website Hosting

Public GitHub Pages deployment for
[bdttalentgroup.com](https://bdttalentgroup.com/).

The private source repository is `BDT-Website-Redesign`. This repository should
contain only the static files needed to publish the website; do not commit
credentials, environment files, or private development material here.

## Validation

Run the dependency-free site check before publishing:

```sh
python3 scripts/check_site.py
```
